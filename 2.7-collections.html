1 — Collections

Collections ist der Überbegriff für Klassen der Java-Bibliothek, die das strukturierte Speichern mehrerer (gleichartiger) Objekte ermöglichen. Sie sind einfacher zu verwenden als Arrays: Um die Organisation der Daten – Weiterschieben beim Einfügen, Vorrücken beim Löschen – muss man sich nicht kümmern, das ist schon umgesetzt.

Collections sind nicht für einen bestimmten Datentyp gebaut. Bei der Verwendung gibt man den Typ als Typparameter in spitzen Klammern an: ArrayList<Student> ist eine ArrayList von Studenten, LinkedList<Fahrzeug> eine LinkedList von Fahrzeugen.

2 — ArrayList: Beispiel Schulklasse

Die ArrayList ist eine der am häufigsten verwendeten Collections – sie setzt die Funktionalität der Objekt-Arrays aus Lektion 2.5 um. Das Beispiel: eine Verwaltungsklasse Klasse (eine Schulklasse) mit beliebig vielen Studenten.

Student hat neben dem Namen ein Geschlecht, umgesetzt als Aufzählungstyp enum: Der Programmierer legt fest, welche Werte dieser Datentyp annehmen kann – hier M, W, D (männlich, weiblich, divers). setKlasse ist Teil der beidseitigen Assoziation und soll nur von Klasse verwendet werden.

In toString wird switch–case verwendet, um Kaskaden von if-Statements zu vermeiden: Nach switch steht eine Variable, deren mögliche Werte unterschiedliche Aktionen auslösen. Nach jedem case folgt der Code für diesen Wert. Achtung: Jeder Block muss mit break beendet werden! Der optionale default-Block wird ausgeführt, wenn keiner der Werte zutrifft.

Student.java Code anzeigen (82 Zeilen)
Student.java Java 
public class Student {

    public enum Geschlecht { M, W, D }; // maennlich, weiblich, divers

    private String name;
    private Geschlecht geschlecht;

    private Klasse klasse;

    public Student() {
        setName("n/a");
        setGeschlecht(Geschlecht.D);
        this.klasse = null;
    }

    public Student(String name, Geschlecht geschlecht) {
        setName(name);
        setGeschlecht(geschlecht);
        this.klasse = null;
    }

    public void setName(String name) {
        if (name != null) {
            this.name = name;
        } else {
            System.out.println("Name ist null");
        }
    }

    public String getName() {
        return name;
    }

    public void setGeschlecht(Geschlecht geschlecht) {
        this.geschlecht = geschlecht;
    }

    public Geschlecht getGeschlecht() {
        return geschlecht;
    }

    public void setKlasse(Klasse klasse) {
        if (klasse != null) {
            if (klasse.enthaelt(this) == true) {
                this.klasse = klasse;
            } else {
                System.out.println("Fehler: Student ist nicht in Klasse enthalten. Klasse kann also nicht bei Student gesetzt werden.");
            }
        } else {
            if (this.klasse == null || !this.klasse.enthaelt(this)) {
                this.klasse = null;
            } else {
                System.out.println("Fehler: Klasse kann nicht null gesetzt werden, da der Student noch in dieser Klasse vorhanden ist.");
            }
        }
    }

    public Klasse getKlasse() {
        return klasse;
    }

    public String toString() {
        String str = "Name: " + name;
        switch (geschlecht) {
            case M: str += " (maennlich)"; break;
            case W: str += " (weiblich)"; break;
            case D: str += " (divers)"; break;
            default: System.out.println("Fehler: ungueltiges Geschlecht");
        }
        str += ", Klasse: ";
        if (klasse != null) {
            str += klasse.getName();
        } else {
            str += " n/a";
        }
        return str;
    }

    public void printStudent() {
        System.out.println(this); // ruft toString() auf
    }
}

Klasse verwaltet die Studenten in einer ArrayList<Student>, die im Konstruktor erzeugt wird. Beim Aufruf des Konstruktors kann der Typparameter weggelassen werden (new ArrayList<>(), „Diamond“).

Klasse.java Code anzeigen (103 Zeilen)
Klasse.java Java 
import java.util.*;

public class Klasse {

    private String name;
    private ArrayList<Student> studenten;

    public Klasse() {
        setName("4ABIF");
        studenten = new ArrayList<>();
    }

    public Klasse(String name) {
        setName(name);
        studenten = new ArrayList<>();
    }

    public void setName(String name) {
        if (name != null) {
            this.name = name;
        } else {
            System.out.println("Ungueltiger Parameter (Name): null");
        }
    }

    public String getName() {
        return name;
    }

    public boolean hinzufuegen(Student stud) {
        return einfuegen(studenten.size(), stud);
    }

    public boolean einfuegen(int position, Student stud) {
        boolean hinzugefuegt = false;
        if (stud != null) {
            if (position >= 0 && position <= studenten.size()) {
                if (stud.getKlasse() == null) {
                    studenten.add(position, stud);
                    stud.setKlasse(this);
                    hinzugefuegt = true;
                } else {
                    System.out.println("Fehler: Student ist schon Teil einer anderen Klasse.");
                }

            } else {
                System.out.println("Fehler: ungueltige position " + position);
            }
        } else {
            System.out.println("Fehler: stud ist null.");
        }
        return hinzugefuegt;
    }

    public boolean entfernen(Student stud) {
        if (stud != null) {
            boolean entfernt = studenten.remove(stud);
            if (entfernt) {
                stud.setKlasse(null);
            }
            return entfernt;
        } else {
            System.out.println("Fehler: stud ist null.");
        }
        return false;
    }

    public Student getStudent(int idx) {
        if (idx >= 0 && idx < studenten.size()) {
            return studenten.get(idx);
        } else {
            System.out.println("Fehler: kein Student an Stelle " + idx + " vorhanden");
            return null;
        }
    }

    public boolean enthaelt(Student stud) {
        if (stud != null) {
            return studenten.contains(stud);
        } else {
            System.out.println("Fehler: stud ist null.");
        }
        return false;
    }

    public String toString() {
        String str = "Klasse: " + getName() + "\n";
        str += "--------------------------------------\n";
        if (studenten.size() > 0) {
            for (Student s : studenten) {
                str += s + "\n";
            }
        } else {
            str += "Keine Studenten im Kurs vorhanden.\n";
        }
        str += "--------------------------------------\n";
        return str;
    }

    public void printKlasse() {
        System.out.println(this);
    }
}

Die Implementierung ist im Vergleich zu Objekt-Arrays wesentlich kürzer und übersichtlicher. hinzufuegen ruft einfuegen auf, da es ein Spezialfall davon ist. In einfuegen werden im Wesentlichen die Parameter geprüft und die beidseitige Assoziation umgesetzt – den Rest erledigt die ArrayList!

3 — Wichtige Methoden und die for-each-Schleife

E steht jeweils für den Typ, der bei der Deklaration in spitzen Klammern angegeben wurde.

In toString von Klasse wird die for-each-Schleife verwendet. Weil es sehr häufig vorkommt, alle Elemente einer Collection zu durchlaufen, bietet Java dafür eine einfachere Syntax als die konventionelle for-Schleife. Über die Referenz s vom Typ Student greift man in der Schleife der Reihe nach auf alle Objekte zu:

for mit Index Java 
for (int i = 0; i < studenten.size(); i++) {
    Student s = studenten.get(i);
    System.out.println(s);
}
for-each Java 
for (Student s : studenten) {
    System.out.println(s);
}
💡
for-each auch für Arrays

Die for-each-Schleife funktioniert auch mit Arrays: for (int w : werte) summe += w;. Den Index hat man darin allerdings nicht.

4 — LinkedList, Set und Map

Die LinkedList<E> unterscheidet sich von der ArrayList<E> durch die interne Verwaltung: Die ArrayList enthält (wie der Name sagt) ein Array, die LinkedList eine verkettete Liste, in der zu jedem Element sein Nachfolger und Vorgänger gespeichert ist.

Die Elemente können daher nicht direkt über einen Index angesprochen werden (get(i) muss sich durchhanteln) – meist eine erhebliche Einschränkung. Vorteile gibt es beim Einfügen an der Stelle, an der man gerade steht: Bei der ArrayList müssen alle folgenden Elemente nach hinten verschoben werden, bei der LinkedList werden nur die Referenzen auf Vorgänger und Nachfolger aktualisiert.

CollectionEigenschaftMehr dazu
Set<E> (HashSet, TreeSet)mathematische Menge: kein Element doppelt, Reihenfolge nicht festgelegtLektion 3.2 – Klassen brauchen dafür Vorkehrungen (equals, hashCode)
Map<K, V> (meist HashMap)mathematische Abbildung: jedem Schlüssel (Key) ist genau ein Wert (Value) zugeordnet; Werte werden über ihren Schlüssel besonders schnell gefunden, ohne eine Liste zu durchsuchenz. B. Map<Long, Employee> Id → Mitarbeiter
HashMap – kurzer Vorgeschmack Java 
HashMap<String, Integer> telefon = new HashMap<>();
telefon.put("Karl", 4711);
telefon.put("Susi", 1234);
System.out.println(telefon.get("Karl"));   // 4711

5 — Iterator

Ein Iterator durchläuft eine Collection unabhängig von ihrer internen Struktur (das Iterator-Pattern, Lektion 3.7). Die for-each-Schleife verwendet intern einen Iterator. Explizit braucht man ihn, wenn man während des Durchlaufens Elemente entfernen will – mit einer for-each-Schleife führt das zu einer ConcurrentModificationException.

Alle Studenten mit Geschlecht D entfernen Java 
Iterator<Student> it = studenten.iterator();
while (it.hasNext()) {             // gibt es noch ein Element?
    Student s = it.next();         // nächstes Element holen
    if (s.getGeschlecht() == Student.Geschlecht.D) {
        it.remove();               // aktuelles Element sicher entfernen
    }
}

6 — Boxing und Unboxing

Collections bzw. generische Klassen im Allgemeinen können nicht mit primitiven Datentypen verwendet werden (ArrayList<int> geht nicht). Will man das dennoch, muss der Wert in eine Klasse „eingepackt“ werden, die ein Attribut dieses Typs hat. Für int könnte sie so aussehen:

IntegerBox.java Java 
import java.util.ArrayList;

class IntegerBox {
    private int wert;

    private IntegerBox(int wert) {
        setWert(wert);
    }

    public static IntegerBox wertVon(int wert) {
        return new IntegerBox(wert);
    }

    public int getWert() {
        return wert;
    }

    public void setWert(int wert) {
        this.wert = wert;
    }

    @Override
    public String toString() {
        return String.valueOf(wert);
    }
}

Objekte werden mit der statischen Methode wertVon erzeugt; der Konstruktor ist nach außen versteckt (private) und wird innerhalb dieser Methode aufgerufen:

IntegerBox verwenden Java 
IntegerBox a = IntegerBox.wertVon(3);
IntegerBox b = IntegerBox.wertVon(5);

ArrayList<IntegerBox> liste = new ArrayList<>();

liste.add(a);
liste.add(b);

System.out.println("Liste: " + liste);

Das „Einpacken“ heißt Boxing, das Auslesen Unboxing. Die passenden Klassen gibt es schon in der Java-Bibliothek: Integer, Double, Boolean, Character, … dein Vorteil: Boxing und Unboxing passieren automatisch – das nennt man Autoboxing.

Autoboxing Java 
Integer a = Integer.valueOf(3);
Integer b = 5;
Integer nullTest = null;

ArrayList<Integer> liste = new ArrayList<>();
liste.add(a);
liste.add(b);
liste.add(7); // auto-boxing
liste.add(nullTest);
int x = 12;
liste.add(x); // auto-boxing
System.out.println("Liste: " + liste);

int z = liste.get(4); // auto-unboxing
System.out.println("z: " + z);
Ausgabe Text 
Liste: [3, 5, 7, null, 12]
z: 12
⚠
null beim Unboxing
int y = liste.get(3); würde hier eine NullPointerException werfen: Ein Integer kann null sein, ein int nicht.

Firma mit ArrayList

Das Array mit anzahl wird durch eine ArrayList<Mitarbeiter> ersetzt. Die Firma hat damit keine Obergrenze mehr, alle Methoden werden kürzer (kein Verschieben, kein Zählen), und die Schleifen werden zu for-each-Schleifen. Die beidseitige Assoziation bleibt unverändert.

src/main/java/Firma.java (Auszug) Java 
import java.util.ArrayList;

public class Firma {

    private String name;
    private ArrayList<Mitarbeiter> personal;

    public Firma(String name) {
        setName(name);
        personal = new ArrayList<>();
    }

    public int anzahlMitarbeiter() {
        return personal.size();
    }

    public boolean einstellen(Mitarbeiter m) {
        return einfuegen(personal.size(), m);
    }

    public boolean einfuegen(int position, Mitarbeiter m) {
        // ... Prüfungen wie bisher ...
        personal.add(position, m);       // ArrayList verschiebt selbst
        m.setFirma(this);
        return true;
    }

    public Mitarbeiter kuendigen(int position) {
        if (position >= 0 && position < personal.size()) {
            Mitarbeiter m = personal.remove(position);
            m.setFirma(null);
            return m;
        }
        // ...
    }

    // Achtung: contains vergleicht mit equals (Inhaltsgleichheit)
    public boolean enthaelt(Mitarbeiter m) {
        return personal.contains(m);
    }

    public int summeKosten() {
        int summe = 0;
        for (Mitarbeiter m : personal) {         // for-each-Schleife
            summe += m.getKostenProMonat();
        }
        return summe;
    }

Häufige Fehler

3 Fehler · zum Aufklappen klicken
Fehler: ArrayList nicht erzeugt

private ArrayList<Student> studenten; und dann studenten.add(s) → NullPointerException.

Im Konstruktor studenten = new ArrayList<>(); aufrufen.

Fehler: Entfernen in der for-each-Schleife

for (Student s : studenten) if (…) studenten.remove(s); → ConcurrentModificationException.

Einen Iterator mit it.remove() verwenden (oder studenten.removeIf(s -> …), Lektion 3.5).

Fehler: break vergessen

Bei case M: wird „(maennlich) (weiblich) (divers)“ angehängt.

Ohne break „fällt“ die Ausführung in die nächsten case-Blöcke durch. Jeden Block mit break; beenden.

Quiz

4 Fragen · zum Aufklappen klicken

Frage 1 Was ist der wichtigste Vorteil einer ArrayList gegenüber einem Array?

Erklärung: Das Verschieben von Elementen und Mitzählen der Anzahl übernimmt die ArrayList. Mit dem Typparameter, z. B. ArrayList<String>, legt man fest, welche Objekte hinein dürfen.

Frage 2 Welche Zeile gibt alle Elemente einer ArrayList<String> namen mit der for-each-Schleife aus?

Erklärung: Die for-each-Schleife lautet for (Typ variable : sammlung). Sie durchläuft jedes Element einmal, ohne Index.

Frage 3 Warum verwendet man einen Iterator, um während des Durchlaufens Elemente zu entfernen?

Erklärung: Die for-each-Schleife verwendet intern selbst einen Iterator. Ändert man die Liste an ihm vorbei, merkt er das und bricht ab.

Frage 4 Warum schreibt man ArrayList<Integer> statt ArrayList<int>?

Erklärung: Typparameter müssen Referenztypen sein. Beim Hinzufügen wird ein int automatisch in ein Integer-Objekt verpackt (Boxing) und beim Lesen wieder ausgepackt (Unboxing).
