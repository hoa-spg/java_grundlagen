1 — Warum selbst sortieren?

Das Sortieren von Inhalten in Arrays ist ein häufiger Anwendungsfall. Nahezu alle Programmiersprachen bieten dafür fertige Methoden (in Java z. B. Arrays.sort und Collections.sort, Lektion 2.9). Hier werden einfache Sortier-Algorithmen vorgestellt und verglichen – das vertieft das Verständnis für Algorithmen und den Umgang mit Arrays.

Ausgangssituation: ein Array mit Zahlen in beliebiger Reihenfolge. Ziel: die Zahlen innerhalb des Arrays aufsteigend sortieren.

2 — Drei einfache Verfahren

VerfahrenIdee
Bubble-SortDas konzeptuell einfachste Verfahren: Das Array durchlaufen und zwei benachbarte Elemente vertauschen, wenn das erste größer als das zweite ist. Den Durchlauf so lange wiederholen, bis nichts mehr getauscht wurde. Die großen Werte „blubbern“ nach hinten.
Selection-SortIn einer äußeren Schleife wird an die aktuelle Stelle der richtige Wert gesetzt: das kleinste Element der weiter hinten liegenden Plätze wird gesucht und hierher getauscht. So entsteht schrittweise ein sortierter Bereich am Anfang.
Insertion-SortFunktioniert wie das Sortieren von Spielkarten in der Hand: Links liegen die schon sortierten Elemente, rechts die unsortierten. In jedem Schritt wird das nächste unsortierte Element genommen und im sortierten Bereich an der richtigen Stelle eingefügt.
Ablauf mit 5, 2, 4, 1 Text 
Bubble-Sort, 1. Durchlauf:   [5 2] 4 1 -> 2 [5 4] 1 -> 2 4 [5 1] -> 2 4 1 5
Selection-Sort, Schritt 1:   kleinstes ist 1 -> tausche mit Platz 0: 1 2 4 5
Insertion-Sort:              5 | 2 4 1  ->  2 5 | 4 1  ->  2 4 5 | 1  ->  1 2 4 5

Daneben gibt es weitaus bessere Verfahren, die vor allem bei großen Datenmengen deutlich schneller sind, weil sie weniger Vergleiche und Vertauschungen brauchen: Quicksort und Merge-Sort. Sie sind konzeptuell schwieriger und brauchen fortgeschrittenere Techniken (Rekursion) und werden hier nicht behandelt. Eine umfassende Darstellung verschiedenster Sortieralgorithmen und ihrer Analyse bietet happycoders.eu/de/algorithmen/sortieralgorithmen.

3 — Codebeispiel: Sortieren

Sortieren.java Java 
import java.util.Random;

public class Sortieren {

    private int[] originalWerte = { 3, 9, 7, 1, 4, -5, 0, 8, 6, 9 };
    private int[] werte;

    public Sortieren() {
        reset();
    }

    public void randomInit(int n) {
        originalWerte = new int[n];
        Random rnd = new Random();
        for (int i = 0; i < originalWerte.length; i++) {
            originalWerte[i] = rnd.nextInt(1000);
        }
    }

    public void reset() {
        werte = new int[originalWerte.length];
        for (int i = 0; i < werte.length; i++) {
            werte[i] = originalWerte[i];
        }
    }

    public void sortieren() {
        randomInit(10000);

        reset();
        bubbleSort();

        reset();
        selectionSort();

        reset();
        insertionSort();
    }

    public void bubbleSort() {
        System.out.print("Bubble Sort... ");
        long startTime = System.currentTimeMillis();
        boolean getauscht = false;
        do {
            getauscht = false;
            // printWerte();
            for (int i = 0; i < werte.length-1; i++) {
                if (werte[i] > werte[i+1]) {
                    tauschen(i, i+1);
                    // printWerte();
                    getauscht = true;
                }
            }
            // System.out.println();
        } while (getauscht);
        long endTime = System.currentTimeMillis();
        System.out.println((endTime - startTime) + " ms");
    }

    public void selectionSort() {
        System.out.print("Selection Sort... ");
        long startTime = System.currentTimeMillis();
        for (int i = 0; i < werte.length; i++) {
            int jMin = i; // wir speichern die Position des kleinsten
                          // Elementes (der verbleibenden Elemente)
            for (int j = i+1; j < werte.length; j++) {
                if (werte[j] < werte[jMin]) {
                    jMin = j;
                }
            }

            tauschen(i, jMin);
        }
        long endTime = System.currentTimeMillis();
        System.out.println((endTime - startTime) + " ms");
    }

    public void insertionSort() {
        System.out.print("Insertion Sort... ");
        long startTime = System.currentTimeMillis();
        for (int i = 1; i < werte.length; i++) {
            for (int j = i; j > 0; j--) {
                if (werte[j] < werte[j-1]) {
                    tauschen(j, j-1);
                }
            }
        }
        long endTime = System.currentTimeMillis();
        System.out.println((endTime - startTime) + " ms");
    }

    public void tauschen(int i, int j) {
        if (i >= 0 && i < werte.length && j >= 0 && j < werte.length /*&& i != j*/) {
            int tmp = werte[i];
            werte[i] = werte[j];
            werte[j] = tmp;
        } else {
            System.out.println("Ungueltige(r) Parameter: " + i + ", " + j);
        }
    }

    public void printWerte() {
        // System.out.println(this.toString());
        System.out.println(this);
    }

    public String toString() {
        String str = "Werte: ";
        // wir zeigen zur Veranschaulichung den gesamten Inhalt an.
        // eigentlich waere i<anzahl richtiger.
        for (int i = 0; i < werte.length; i++) {
            if (i > 0) {
                str += ", ";
            }
            str += werte[i];
        }
        return str;
    }
}

Zuerst wird originalWerte befüllt. Vor jedem Verfahren kopiert reset() den Inhalt nach werte, damit alle Verfahren mit derselben Datengrundlage arbeiten. Wichtig ist das Tauschen über eine Hilfsvariable tmp: Ohne sie wäre einer der beiden Werte verloren.

💡
Insertion-Sort früher abbrechen

In der inneren Schleife von insertionSort kann man aufhören, sobald nicht mehr getauscht wird: for (int j = i; j > 0 && werte[j] < werte[j-1]; j--). Der linke Teil ist ja schon sortiert – so wird das Verfahren bei fast sortierten Daten sehr schnell.

Selection- und Insertion-Sort sind dem einfacheren Bubble-Sort deutlich überlegen. Die genauen Zahlen hängen vom Rechner ab – das Verhältnis bleibt ähnlich.

ℹ
Warum „langsam“?

Alle drei Verfahren vergleichen im schlechtesten Fall jedes Element mit (fast) jedem anderen: Bei n Werten sind das rund n²/2 Vergleiche. Doppelt so viele Werte bedeuten also etwa viermal so lange Laufzeit. Quicksort und Merge-Sort kommen mit etwa n · log n aus.

Sortierte Buchungen und Median

Die Zeiterfassung liefert eine sortierte Kopie ihrer Buchungen (Insertion-Sort mit vorzeitigem Abbruch) und berechnet daraus den Median – den mittleren Wert, der im Gegensatz zum Durchschnitt nicht von einzelnen Ausreißern verzerrt wird. Die Reihenfolge der Buchungen selbst bleibt unverändert.

src/main/java/Zeiterfassung.java (neue Methoden) Java 
// liefert eine sortierte KOPIE der gültigen Buchungen (Insertion-Sort);
// die Reihenfolge in "buchungen" bleibt unverändert
public int[] sortiert() {
    int[] kopie = new int[anzahl];
    for (int i = 0; i < anzahl; i++) {
        kopie[i] = buchungen[i];
    }
    for (int i = 1; i < kopie.length; i++) {
        for (int j = i; j > 0 && kopie[j] < kopie[j - 1]; j--) {
            int tmp = kopie[j];
            kopie[j] = kopie[j - 1];
            kopie[j - 1] = tmp;
        }
    }
    return kopie;
}

// Median: der "mittlere" Wert der sortierten Buchungen
public double median() {
    if (anzahl == 0) {
        return 0;
    }
    int[] s = sortiert();
    if (s.length % 2 == 1) {
        return s[s.length / 2];
    } else {
        return (s[s.length / 2 - 1] + s[s.length / 2]) / 2.0;
    }
}

Der Operator % liefert den Rest der Division: s.length % 2 == 1 heißt „ungerade Anzahl“. Getestet wird mit assertArrayEquals(new int[] {6, 8, 10}, z.sortiert()).

Häufige Fehler

3 Fehler · zum Aufklappen klicken
Fehler: Tauschen ohne Hilfsvariable

werte[i] = werte[j]; werte[j] = werte[i]; – danach stehen zwei gleiche Werte im Array.

Einen Wert zwischenspeichern: int tmp = werte[i]; werte[i] = werte[j]; werte[j] = tmp;.

Fehler: Index i+1 außerhalb

Bubble-Sort mit for (int i = 0; i < werte.length; i++) und Zugriff auf werte[i+1] → ArrayIndexOutOfBoundsException.

Beim Vergleich mit dem Nachbarn nur bis werte.length - 1 laufen.

Fehler: Kopie ist keine Kopie

Nach int[] kopie = werte; und Sortieren von kopie ist auch werte sortiert.

Arrays sind Referenzen. Eine echte Kopie braucht ein neues Array (new int[…]) und eine Schleife, die die Werte kopiert (oder werte.clone()).

Quiz

4 Fragen · zum Aufklappen klicken

Frage 1 Welche Idee steckt hinter Bubble-Sort?

Erklärung: Bei jedem Durchlauf „blubbert“ der größte verbleibende Wert ans Ende. Option 1 beschreibt Selection-Sort, Option 3 Insertion-Sort, Option 4 Merge-Sort.

Frage 2 Wie tauscht man die Werte an den Indizes i und j richtig?

Erklärung: Ohne Hilfsvariable ist der alte Wert von a[i] nach der ersten Zuweisung verloren und beide Plätze haben denselben Wert.

Frage 3 Warum wird das Array vor jedem Sortierverfahren kopiert?

Erklärung: Ein bereits sortiertes Array wäre für manche Verfahren viel schneller erledigt – der Vergleich wäre unfair.

Frage 4 Was misst System.currentTimeMillis()?

Erklärung: Man merkt sich die Zeit vor und nach dem Sortieren und zieht ab. Für aussagekräftige Werte braucht man große Arrays.
