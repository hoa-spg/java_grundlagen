1 — Referenzdatentypen und Objektreferenzen

Java unterscheidet zwei Arten von Datentypen. Bei einem primitiven Datentyp (int, double, boolean, …) steht der Wert direkt in der Variable. Jede Klasse – auch String und jede selbst geschriebene Klasse – ist dagegen ein Referenzdatentyp. Eine Variable, ein Parameter oder ein Attribut eines Referenzdatentyps enthält nicht das Objekt selbst, sondern eine Objektreferenz: einen Verweis auf das Objekt, das an anderer Stelle im Speicher liegt.

Werte und Objektreferenzen Java 
int alter = 30;                  // die Variable enthält den Wert 30
Kunde k1 = new Kunde("Anna");    // new erzeugt ein Objekt und liefert eine Objektreferenz darauf
Kunde k2 = k1;                   // kopiert wird nur die Objektreferenz, nicht das Objekt
k2.setName("Berta");             // ändert das eine gemeinsame Objekt: auch k1.getName() liefert "Berta"
Kunde k3 = null;                 // keine Objektreferenz: k3 verweist auf kein Objekt

Über eine Objektreferenz ruft man Methoden des Objekts auf (k1.getName()). Ist die Objektreferenz null, gibt es kein Objekt – der Aufruf bricht mit einer NullPointerException ab.

Weil auch Attribute einen Referenzdatentyp haben können, kann ein Objekt Objektreferenzen auf andere Objekte speichern. Genau so entstehen Beziehungen zwischen Objekten.

2 — Objekte stehen in Beziehung

Oft stehen Objekte in Beziehung zueinander. Ein häufiger Fall: In Objekten einer Klasse werden mehrere Instanzen einer anderen Klasse verwaltet. In Lektion 1.6 wurde die Klasse Person entwickelt; jetzt entsteht eine Klasse Auto, in die bis zu drei Personen „einsteigen“ können.

Die Plätze im Auto sind Attribute des Referenzdatentyps Person, sie enthalten also Objektreferenzen auf Person-Objekte. Steigt eine Person ein, wird im Auto-Objekt eine Objektreferenz auf das Person-Objekt gespeichert. Hat fahrer, beifahrer oder rueckbank den Wert null, sitzt auf diesem Platz niemand.

Klassendiagramm (vereinfacht) Text 
+-------------------+   fahrer, beifahrer,   +------------------+
|       Auto        |   rueckbank (0..3)     |      Person      |
|-------------------| ---------------------> |------------------|
| name: String      |                        | name: String     |
| eigengewicht: int |                        | gewicht: int ... |
+-------------------+                        +------------------+

Der Pfeil zeigt die Richtung der Beziehung: Ein Auto kennt seine Insassen, eine Person weiß aber nicht, in welchem Auto sie sitzt.

3 — Die Klasse Auto

Die Klasse Person wird dabei mit ihrer Methode printPerson() (Lektion 1.6) und einer Get-Methode getGewicht() vorausgesetzt.

Auto.java Java 
public class Auto {

    private String name;
    private int eigengewicht;

    private Person fahrer;
    private Person beifahrer;
    private Person rueckbank;

    public Auto() {
        setName("n/a");
        setEigengewicht(1300);
    }

    public Auto(String name, int eigengewicht) {
        setName(name);
        setEigengewicht(eigengewicht);
    }

    public String getName() {
        return name;
    }

    public int getEigengewicht() {
        return eigengewicht;
    }

    public void setName(String name) {
        if (name != null) {
            this.name = name;
        } else {
            System.out.println("Fehler: kein Name!");
            this.name = "n/a";
        }
    }

    public void setEigengewicht(int eigengewicht) {
        if ((eigengewicht >= 600) && (eigengewicht <= 3000)) {
            this.eigengewicht = eigengewicht;
        } else {
            System.out.println("Fehler: kein gültiges Eigengewicht (600..3000)!");
            this.eigengewicht = 1300;
        }
    }

    public void einsteigen(Person person) {
        // 1. Pruefung ob die Objektreferenz person nicht null ist
        if (person != null) {
            if (this.fahrer == null) {
                this.fahrer = person; // this kann man hier weglassen
            } else {
                if (this.beifahrer == null) {
                    this.beifahrer = person;
                } else {
                    if (this.rueckbank == null) {
                        this.rueckbank = person;
                    } else {
                        System.out.println("Fehler: das Auto ist voll!");
                    }
                }
            }
        } else { // entsprechende Fehlermeldung
            System.out.println("Fehler: Parameter person ist null!");
        }
    }

    public void aussteigenFahrer() {
        fahrer = null;
    }

    public void aussteigenBeifahrer() {
        beifahrer = null;
    }

    public void aussteigenRueckbank() {
        rueckbank = null;
    }

    public void aussteigen(Person person) {
        if (person != null) {
            if (this.fahrer == person) {
                aussteigenFahrer();
            } else {
                if (this.beifahrer == person) {
                    aussteigenBeifahrer();
                } else {
                    if (this.rueckbank == person) {
                        aussteigenRueckbank();
                    } else {
                        System.out.println("Fehler: Person nicht im Auto.");
                    }
                }
            }
        } else {
            System.out.println("Fehler: Parameter person ist null.");
        }
    }

    public void aussteigen(String name) {
        if (name != null) {
            // Achtung: String-Vergleich immer mit der equals-Methode!
            if (this.fahrer != null && name.equals(fahrer.getName())) {
                aussteigenFahrer();
            } else {
                if (this.beifahrer != null && name.equals(beifahrer.getName())) {
                    aussteigenBeifahrer();
                } else {
                    if (this.rueckbank != null && name.equals(rueckbank.getName())) {
                        aussteigenRueckbank();
                    } else {
                        System.out.println("Fehler: Person nicht im Fahrzeug");
                    }
                }
            }
        } else {
            System.out.println("Fehler: name ist null.");
        }
    }

    public int gesamtGewicht() {
        int gesamtGewicht = getEigengewicht();

        if (this.fahrer != null) {
            gesamtGewicht = gesamtGewicht + this.fahrer.getGewicht();
        }

        if (this.beifahrer != null) {
            gesamtGewicht = gesamtGewicht + this.beifahrer.getGewicht();
        }

        if (this.rueckbank != null) {
            gesamtGewicht = gesamtGewicht + this.rueckbank.getGewicht();
        }

        return gesamtGewicht;
    }

    public void printAuto() {
        System.out.println("Auto: " + name + ", Eigengewicht: " + eigengewicht);
        System.out.println("--------------------------------------------------------");

        System.out.print("Fahrer: ");
        if (this.fahrer != null) {
            this.fahrer.printPerson();
        } else {
            System.out.println(" --frei-- ");
        }

        System.out.print("Beifahrer: ");
        if (this.beifahrer != null) {
            this.beifahrer.printPerson();
        } else {
            System.out.println(" --frei--");
        }

        System.out.print("Rueckbank: ");
        if (this.rueckbank != null) {
            this.rueckbank.printPerson();
        } else {
            System.out.println(" --frei--");
        }

        System.out.println("--------------------------------------------------------");
    }
}

4 — Einsteigen: den ersten freien Platz finden

Die wesentlichen Überlegungen stecken in einsteigen(Person person). Der Parameter person übergibt die Objektreferenz auf die einsteigende Person. Die Logik: Die Person nimmt den ersten freien Platz – Fahrer, dann Beifahrer, dann Rückbank.

  1. Prüfen, ob person ungleich null ist, sonst Fehlermeldung.
  2. Ist fahrer == null, sitzt dort noch niemand → this.fahrer = person;
  3. Anderenfalls Beifahrer, dann Rückbank prüfen.
  4. Kein Platz frei → Fehlermeldung „das Auto ist voll“.

Mit else if wird dieselbe Logik deutlich flacher:

einsteigen – Variante mit else if Java 
public void einsteigen(Person person) {
    if (person == null) {
        System.out.println("Fehler: Parameter person ist null!");
    } else if (fahrer == null) {
        fahrer = person;
    } else if (beifahrer == null) {
        beifahrer = person;
    } else if (rueckbank == null) {
        rueckbank = person;
    } else {
        System.out.println("Fehler: das Auto ist voll!");
    }
}

5 — Aussteigen: Objektreferenzen vergleichen

aussteigen(Person person) ist ähnlich aufgebaut, vergleicht aber, ob die übergebene Objektreferenz gleich einem der Plätze ist (this.fahrer == person). Bei Referenzdatentypen prüft ==, ob beide Objektreferenzen auf dasselbe Objekt verweisen. Ist das der Fall, setzt die passende Methode den Platz auf null.

In aussteigen(String name) soll die Person aussteigen, deren Name übereinstimmt. Zuerst muss name auf null geprüft werden – sonst führt name.equals(…) zu einer NullPointerException. Die Bedingungen sind etwas komplexer:

Bedingung mit zwei Teilen Java 
if (this.fahrer != null && name.equals(fahrer.getName())) {
  • Zuerst wird geprüft, ob auf dem Platz jemand sitzt (this.fahrer != null).
  • Erst nach && wird der Name verglichen. Ist die linke Seite false, wertet Java die rechte gar nicht mehr aus (Kurzschlussauswertung) – fahrer.getName() wird also nie auf null aufgerufen.
✗
Strings mit equals vergleichen

Bei String-Vergleichen muss immer die equals-Methode verwendet werden. Der ==-Operator liefert nicht immer das korrekte Ergebnis (siehe Lektion 1.8).

gesamtGewicht() zeigt, wie man über Objektreferenzen Methoden anderer Objekte aufruft: Für jeden besetzten Platz wird getGewicht() der Person zum Eigengewicht addiert.

Die Firma mit drei Plätzen

Analog zum Auto entsteht die Klasse Firma mit drei Plätzen ma1, ma2, ma3 für Mitarbeiter: einstellen (erster freier Platz), kündigen (Vergleich der Objektreferenzen), kündigen nach Namen (wie aussteigen(String name) mit equals), Anzahl und Summe der Kosten. src/main/java/Firma.java Java 
/*
  Personalverwaltung – eine Firma mit bis zu drei Mitarbeitern.
  Stand: Lektion 1.9 (Objekt-Beziehungen)
*/
public class Firma {

    private String name;

    // Objektreferenzen auf Mitarbeiter; null bedeutet: Platz frei
    private Mitarbeiter ma1;
    private Mitarbeiter ma2;
    private Mitarbeiter ma3;

    public Firma() {
        setName("n/a");
    }

    public Firma(String name) {
        setName(name);
    }

    public String getName() {
        return name;
    }

    public void setName(String name) {
        if (name != null) {
            this.name = name;
        } else {
            System.out.println("Fehler: name darf nicht null sein");
            this.name = "n/a";
        }
    }

    public void einstellen(Mitarbeiter m) {
        if (m != null) {
            if (ma1 == null) {
                ma1 = m;
            } else if (ma2 == null) {
                ma2 = m;
            } else if (ma3 == null) {
                ma3 = m;
            } else {
                System.out.println("Fehler: kein freier Platz in der Firma!");
            }
        } else {
            System.out.println("Fehler: Parameter m ist null!");
        }
    }

    public void kuendigen(Mitarbeiter m) {
        if (m != null) {
            // Vergleich der Objektreferenzen: ist es DERSELBE Mitarbeiter?
            if (ma1 == m) {
                ma1 = null;
            } else if (ma2 == m) {
                ma2 = null;
            } else if (ma3 == m) {
                ma3 = null;
            } else {
                System.out.println("Fehler: Mitarbeiter arbeitet nicht in der Firma.");
            }
        } else {
            System.out.println("Fehler: Parameter m ist null!");
        }
    }

    public void kuendigen(String name) {
        if (name != null) {
            // Achtung: Strings immer mit equals vergleichen, nie mit ==
            if (ma1 != null && name.equals(ma1.getName())) {
                ma1 = null;
            } else if (ma2 != null && name.equals(ma2.getName())) {
                ma2 = null;
            } else if (ma3 != null && name.equals(ma3.getName())) {
                ma3 = null;
            } else {
                System.out.println("Fehler: kein Mitarbeiter mit Namen " + name);
            }
        } else {
            System.out.println("Fehler: name ist null!");
        }
    }

    public int anzahlMitarbeiter() {
        int anzahl = 0;
        if (ma1 != null) {
            anzahl++;
        }
        if (ma2 != null) {
            anzahl++;
        }
        if (ma3 != null) {
            anzahl++;
        }
        return anzahl;
    }

    public int summeKosten() {
        int summe = 0;
        if (ma1 != null) {
            summe = summe + ma1.getKostenProMonat();
        }
        if (ma2 != null) {
            summe = summe + ma2.getKostenProMonat();
        }
        if (ma3 != null) {
            summe = summe + ma3.getKostenProMonat();
        }
        return summe;
    }

    public void print() {
        System.out.println("Firma: " + name);
        System.out.println("-----------------------------------------------");
        System.out.print("Platz 1: ");
        if (ma1 != null) {
            ma1.print();
        } else {
            System.out.println("--frei--");
        }
        System.out.print("Platz 2: ");
        if (ma2 != null) {
            ma2.print();
        } else {
            System.out.println("--frei--");
        }
        System.out.print("Platz 3: ");
        if (ma3 != null) {
            ma3.print();
        } else {
            System.out.println("--frei--");
        }
        System.out.println("-----------------------------------------------");
        System.out.println("Kosten pro Monat: " + summeKosten() + " Euro");
    }
}

📁 Stand nach dieser Lektion: beispiele/1.9/

Häufige Fehler

Fehler: Methode auf leerem Platz aufgerufen

gesamtGewicht() bricht mit NullPointerException ab, sobald ein Platz frei ist.

Vor jedem Zugriff prüfen: if (fahrer != null) { … fahrer.getGewicht() … }.

Fehler: Person sitzt auf allen Plätzen

Nach einem einsteigen sind alle drei Plätze mit derselben Person belegt.

Die Prüfungen wurden als drei unabhängige if geschrieben. Es braucht else bzw. else if, damit nach dem ersten freien Platz Schluss ist.

Fehler: Reihenfolge in der Bedingung

if (name.equals(fahrer.getName()) && fahrer != null) stürzt ab, wenn der Fahrersitz frei ist.

Die null-Prüfung muss links von && stehen – die rechte Seite wird nur ausgewertet, wenn die linke wahr ist.

Wissenskontrolle

Frage 1 Ein Attribut hat einen Referenzdatentyp (z. B. private Kunde kunde;) und wird im Konstruktor nicht gesetzt. Welchen Wert hat es nach dem Erzeugen des Objekts?

Erklärung: Attribute eines Referenzdatentyps starten mit null – sie enthalten keine Objektreferenz. Bei Objekt-Beziehungen lässt sich null als „noch keine Beziehung“ bzw. „Platz frei“ deuten.

Frage 2 Was prüft a == b, wenn a und b Objektreferenzen sind?

Erklärung: Bei Referenzdatentypen vergleicht == die Objektreferenzen. Zwei verschiedene Objekte mit gleichen Daten sind nicht ==.

Frage 3 Warum prüft man vor einem Aufruf wie ref.methode() oft if (ref != null)?

Erklärung: Ist die Objektreferenz null, gibt es auch keine Methode, die aufgerufen werden könnte – das Programm bricht ab.
