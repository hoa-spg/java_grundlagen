1 — Model-Klassen

In diesem Kapitel stehen die Model-Klassen für die folgenden Abschnitte der Oberflächenentwicklung (Teil 4). Model-Klassen enthalten die Daten und die fachliche Logik (Prüfungen, Berechnungen, Laden/Speichern) – aber keinen Code für die Oberfläche. Die Oberfläche (View) ruft ihre Methoden auf und fängt ihre Exceptions, um Fehlermeldungen anzuzeigen. So lässt sich dieselbe Logik mit JUnit testen und in verschiedenen Oberflächen verwenden.

Die Klassen Company und Employee entsprechen der Personalverwaltung aus den bisherigen Lektionen, verwenden aber englische Namen und mehr Attribute (E-Mail, Telefon, Geburtsdatum, Rolle, Gehalt). Sie liegen im Package at.spengergasse.company.model.

ℹ
Packages

Größere Projekte ordnen Klassen in Packages (Ordner) ein. Die erste Zeile package at.spengergasse.company.model; muss zum Ordner src/main/java/at/spengergasse/company/model/ passen. Klassen aus anderen Packages werden mit import verwendet, z. B. import at.spengergasse.company.model.Company;.

    private String companyName;

    private ArrayList<Employee> staff;

Gleich zu Beginn sieht man: Der Konstruktor ist private. Instanzen von Company erhält man nur über public static Company getInstance(); intern ist sichergestellt, dass nur eine einzige Instanz existiert (Singleton-Pattern, Lektion 3.7). Jede View der Webanwendung arbeitet so mit derselben Firma. CSV_DELIMITER ist eine Konstante (static final, Großbuchstaben).

Company.java – Mitarbeiter einstellen und entlassen Java 
public void hire(Employee emp) throws CompanyException {
    if (emp == null) {
        throw new CompanyException("Error: invalid employee: null. ");
    }
    if (emp.getId() == null) {
        emp.setId(Employee.idCounter++);
    }
    if (staff.contains(emp)) {
        throw new CompanyException("Error: employee already exists in company. ");
    }
    staff.add(emp);
}

/**
 * Alle (!) Mitarbeiter mit diesem Namen werden entfernt. Beim Entfernen
 * während des Durchlaufens muss ein Iterator verwendet werden (keine
 * for-each-Schleife -> ConcurrentModificationException).
 */
public boolean fire(String firstName, String lastName) throws CompanyException {
    if (firstName == null || lastName == null) {
        throw new CompanyException("Error: invalid parameters "
                                   + "(null values are not allowed). ");
    }
    boolean removed = false;
    Iterator<Employee> it = staff.iterator();
    while (it.hasNext()) {
        Employee e = it.next();
        if (e.getLastName().equals(lastName) && e.getFirstName().equals(firstName)) {
            it.remove();
            removed = true;
        }
    }
    return removed;
}

// Kopie der Liste: von außen kann die interne Liste nicht verändert werden
public List<Employee> getStaff() {
    return new ArrayList<>(staff);
}

fire verwendet einen Iterator (das Iterator-Pattern als Teil der Java-Bibliothek), um alle Employees zu durchlaufen und bei Namensgleichheit zu löschen. Will man mehrere Elemente aus einer Collection löschen, darf keinesfalls eine for-each-Schleife verwendet werden – man erhält sonst eine ConcurrentModificationException. getStaff() gibt eine Kopie zurück: Wer die Liste von außen leert, ändert die Firma nicht (vgl. „kein getWerte()“ in Lektion 2.3).

Die Methoden danach verwenden die Streams-API zum Sortieren, Filtern und Verändern:

Company.java – Streams Java 
public int numberOfManagers() {
    return (int) staff.stream()
                      .filter(e -> e.getRole().equals(Employee.Role.MANAGER))
                      .count();
}

public List<Employee> employeesSortedLastName() {
    ArrayList<Employee> sorted = new ArrayList<>(staff);
    sorted.sort(Comparator.comparing(Employee::getLastName));
    return sorted;
}

public List<Employee> employeesSortedSalaryDecreasing(int minSalary) {
    return staff.stream()
                .filter(e -> (e.getSalary() > minSalary))
                .sorted((Employee a, Employee b) -> (b.getSalary() - a.getSalary()))
                .collect(Collectors.toList());
}

public void increaseSalaryByPercent(int percent) throws CompanyException {
    if (percent <= 0 || percent > 100) {
        throw new CompanyException("Error: invalid percentage provided. ");
    }
    // Im Lambda sind keine checked Exceptions erlaubt -> umverpacken
    staff.forEach(e -> {
        try {
            e.setSalary((int) (e.getSalary() * (100 + percent) / 100.0));
        } catch (CompanyException ex) {
            throw new RuntimeException(ex);
        }
    });
}

  • Long id: eine eindeutige Nummer. Long (nicht long), damit null „noch nicht eingestellt“ bedeuten kann. hire vergibt die nächste freie Id.
  • enum Role: nur die fünf festgelegten Rollen sind möglich. Im CSV-Konstruktor werden die Texte mit switch zugeordnet.
  • LocalDate (aus java.time) für das Geburtsdatum, z. B. LocalDate.of(1938, 1, 10). Für CSV wird es mit DateTimeFormatter.ofPattern("yyyy-MM-dd") formatiert bzw. mit LocalDate.parse gelesen; ein falsches Datum führt zu einer DateTimeParseException, die in eine CompanyException umgewandelt wird.
  • JavaBeans-Konvention: Jedes Attribut xyz hat getXyz() und setXyz(…) (bei boolean: isXyz()). Daran erkennt der Vaadin-Binder in Teil 4 die Eigenschaften und bindet sie automatisch an gleichnamige Formularfelder.
  • equals/hashCode über die Id: zwei Employee-Objekte mit gleicher Id sind derselbe Mitarbeiter.

package at.spengergasse.company.model;

import java.io.Serializable;
import java.time.LocalDate;
import java.time.format.DateTimeFormatter;
import java.time.format.DateTimeParseException;
import java.util.Objects;

/**
 * Model-Klasse für einen Mitarbeiter – Basis für die Weboberfläche (Teil 4).
 * Die Get-/Set-Methoden folgen der JavaBeans-Konvention, damit der
 * Vaadin-Binder die Attribute automatisch an Formularfelder binden kann.
 */
public class Employee implements Serializable {

    private static final long serialVersionUID = 1L;

    private static final int MAX_SALARY = 100000;
    private static final int MIN_SALARY = 1500;
    public static Long idCounter = 1000L;

    // konsistent halten mit dem CSV-Konstruktor
    public enum Role { ADMIN, ASSISTANT, DEVELOPER, ANALYST, MANAGER }

    private Long id;               // null = noch nicht eingestellt
    private String firstName;
    private String lastName;
    private String email;
    private String phone;
    private LocalDate dateOfBirth;
    private Role role;
    private int salary;            // Bruttogehalt pro Monat
    private boolean subcontractor;

    public Employee() {
        id = null;
        firstName = "[first name not set]";
        lastName = "[last name not set]";
        email = "office@spengergasse.at";
        phone = "+43 1 54615 0";
        dateOfBirth = LocalDate.of(1970, 1, 1);
        role = Role.ADMIN;
        salary = 2000;
        subcontractor = false;
    }

    public Employee(String firstName, String lastName, String email,
                    String phone, LocalDate dateOfBirth,
                    Role role, int salary, boolean subcontractor)
            throws CompanyException
    {
        this(Employee.idCounter, firstName, lastName, email, phone, dateOfBirth,
             role, salary, subcontractor);
    }

    public Employee(Long id, String firstName, String lastName, String email,
                    String phone, LocalDate dateOfBirth,
                    Role role, int salary, boolean subcontractor)
            throws CompanyException
    {
        setId(id);
        setFirstName(firstName);
        setLastName(lastName);
        setEmail(email);
        setPhone(phone);
        setDateOfBirth(dateOfBirth);
        setRole(role);
        setSalary(salary);
        setSubcontractor(subcontractor);
    }

    // CSV: 1001;Donald;Knuth;knuth@spengergasse.at;+43 1 54615 101;1938-01-10;DEVELOPER;12000;Employee
    public Employee(String csvString) throws CompanyException {
        if (csvString == null) {
            throw new CompanyException("Error: csvString is null. ");
        }
        String[] tokens = csvString.split(Company.CSV_DELIMITER);
        if (tokens.length < 9) {
            throw new CompanyException("Error: invalid csv line: " + csvString
                                       + ". Not enough values (columns). ");
        }
        try {
            setId(Long.parseLong(tokens[0]));
        } catch (NumberFormatException e) {
            throw new CompanyException("Error: invalid id in line " + csvString + ". ", e);
        }
        setFirstName(tokens[1]);
        setLastName(tokens[2]);
        setEmail(tokens[3]);
        setPhone(tokens[4]);
        try {
            DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd");
            setDateOfBirth(LocalDate.parse(tokens[5], formatter));
        } catch (DateTimeParseException e) {
            throw new CompanyException("Error: could not read date in line "
                                       + csvString + ". ", e);
        }
        switch (tokens[6]) {
            case "ADMIN": setRole(Role.ADMIN); break;
            case "ASSISTANT": setRole(Role.ASSISTANT); break;
            case "DEVELOPER": setRole(Role.DEVELOPER); break;
            case "ANALYST": setRole(Role.ANALYST); break;
            case "MANAGER": setRole(Role.MANAGER); break;
            default: throw new CompanyException("Error: invalid role value in line "
                                                + csvString + ". ");
        }
        try {
            setSalary(Integer.parseInt(tokens[7]));
        } catch (NumberFormatException e) {
            throw new CompanyException("Error: invalid salary in line " + csvString + ". ", e);
        }
        if ("Employee".equals(tokens[8])) {
            setSubcontractor(false);
        } else if ("Subcontractor".equals(tokens[8])) {
            setSubcontractor(true);
        } else {
            throw new CompanyException("Error: invalid employment status in line "
                                       + csvString
                                       + ". Expected: 'Employee' or 'Subcontractor'.");
        }
    }

    public Long getId() {
        return id;
    }

    public void setId(Long id) throws CompanyException {
        if (id == null || id < 0) {
            throw new CompanyException("Error: invalid id: " + id);
        }
        if (id >= Employee.idCounter) {
            Employee.idCounter = id + 1;   // nächste freie Id
        }
        this.id = id;
    }

    public String getFirstName() {
        return firstName;
    }

    public void setFirstName(String firstName) throws CompanyException {
        if (firstName == null || firstName.length() <= 2 || firstName.isBlank()) {
            throw new CompanyException("Error: invalid first name: " + firstName);
        }
        this.firstName = firstName;
    }

    public String getLastName() {
        return lastName;
    }

    public void setLastName(String lastName) throws CompanyException {
        if (lastName == null || lastName.length() <= 2 || lastName.isBlank()) {
            throw new CompanyException("Error: invalid last name: " + lastName);
        }
        this.lastName = lastName;
    }

    public String getEmail() {
        return email;
    }

    public void setEmail(String email) throws CompanyException {
        if (email == null || email.length() <= 5 || !email.contains("@")
            || !email.contains("."))
        {
            throw new CompanyException("Error: invalid email address: " + email);
        }
        this.email = email;
    }

    public String getPhone() {
        return phone;
    }

    public void setPhone(String phone) throws CompanyException {
        if (phone == null) {
            throw new CompanyException("Error: invalid phone (null). ");
        }
        this.phone = phone;
    }

    public LocalDate getDateOfBirth() {
        return dateOfBirth;
    }

    public void setDateOfBirth(LocalDate dateOfBirth) {
        this.dateOfBirth = dateOfBirth;
    }

    public Role getRole() {
        return role;
    }

    public void setRole(Role role) throws CompanyException {
        if (role == null) {
            throw new CompanyException("Error: invalid role " + role);
        }
        this.role = role;
    }

    public int getSalary() {
        return salary;
    }

    public void setSalary(int salary) throws CompanyException {
        if (salary <= MIN_SALARY || salary >= MAX_SALARY) {
            throw new CompanyException("Error: invalid salary: " + salary);
        }
        this.salary = salary;
    }

    public boolean isSubcontractor() {
        return subcontractor;
    }

    public void setSubcontractor(boolean subcontractor) {
        this.subcontractor = subcontractor;
    }

    // Zwei Employees sind gleich, wenn sie dieselbe Id haben
    @Override
    public boolean equals(Object o) {
        if (this == o) return true;
        if (o == null || getClass() != o.getClass()) return false;
        Employee employee = (Employee) o;
        return id != null && id.equals(employee.id);
    }

    @Override
    public int hashCode() {
        return Objects.hashCode(id);
    }

    public String toCsvString() {
        DateTimeFormatter formatter = DateTimeFormatter.ofPattern("yyyy-MM-dd");
        String d = Company.CSV_DELIMITER;
        return id + d + firstName + d + lastName + d + email + d + phone + d
               + formatter.format(dateOfBirth) + d + role + d + salary + d
               + (subcontractor ? "Subcontractor" : "Employee");
    }

    @Override
    public String toString() {
        return firstName + " " + lastName
               + " (E: " + email + ", P: " + phone + "), "
               + "date of birth: " + dateOfBirth
               + ", role: " + role
               + ", gross salary: " + salary + " per month, "
               + (subcontractor ? "Subcontractor" : "Employee")
               + ", id=" + id;
    }
}

/**
 * Die Firma als Singleton: in der ganzen Anwendung gibt es genau eine
 * Instanz, die über Company.getInstance() erreichbar ist.
 */
public class Company implements Serializable {

    private static final long serialVersionUID = 1L;

    public static final String CSV_DELIMITER = ";";

    private String companyName;
    private String companyAddress;
    private ArrayList<Employee> staff;

    // ---- Singleton ---------------------------------------------------------

    private static Company companyInstance = null;

    private Company() {
        staff = new ArrayList<>();
        companyName = "n/a";
        companyAddress = "n/a";
    }

    public static Company getInstance() {
        if (companyInstance == null) {
            companyInstance = new Company();
            try {
                companyInstance.fillDebugData();
            } catch (CompanyException e) {
                e.printStackTrace();
            }
        }
        return companyInstance;
    }

    public static void loadFromFile(InputStream is) throws CompanyException {
        companyInstance = Company.readFromFile(is);
    }

    public static void loadFromFile(String filename) throws CompanyException {
        companyInstance = Company.readFromFile(filename);
    }

    public static void clearInstance() {
        companyInstance = null;
    }

    // ---- Get-/Set-Methoden ---------------------------------------------------

    public String getCompanyName() {
        return companyName;
    }

    public void setCompanyName(String companyName) throws CompanyException {
        if (companyName == null || companyName.isBlank()) {
            throw new CompanyException("Invalid company name: null or empty. ");
        }
        this.companyName = companyName;
    }

    public String getCompanyAddress() {
        return companyAddress;
    }

    public void setCompanyAddress(String companyAddress) throws CompanyException {
        if (companyAddress == null || companyAddress.isBlank()) {
            throw new CompanyException("Invalid company address: null or empty. ");
        }
        this.companyAddress = companyAddress;
    }

    // ---- Personal ------------------------------------------------------------

    public void hire(Employee emp) throws CompanyException {
        if (emp == null) {
            throw new CompanyException("Error: invalid employee: null. ");
        }
        if (emp.getId() == null) {
            emp.setId(Employee.idCounter++);
        }
        if (staff.contains(emp)) {
            throw new CompanyException("Error: employee already exists in company. ");
        }
        staff.add(emp);
    }

    public boolean fire(Employee emp) throws CompanyException {
        if (emp == null) {
            throw new CompanyException("Error: employee is null. ");
        }
        return staff.remove(emp);   // nicht vorhanden ist kein Fehler
    }

    /**
     * Alle (!) Mitarbeiter mit diesem Namen werden entfernt. Beim Entfernen
     * während des Durchlaufens muss ein Iterator verwendet werden (keine
     * for-each-Schleife -> ConcurrentModificationException).
     */
    public boolean fire(String firstName, String lastName) throws CompanyException {
        if (firstName == null || lastName == null) {
            throw new CompanyException("Error: invalid parameters "
                                       + "(null values are not allowed). ");
        }
        boolean removed = false;
        Iterator<Employee> it = staff.iterator();
        while (it.hasNext()) {
            Employee e = it.next();
            if (e.getLastName().equals(lastName) && e.getFirstName().equals(firstName)) {
                it.remove();
                removed = true;
            }
        }
        return removed;
    }

    public boolean fire(Long id) throws CompanyException {
        if (id == null) {
            throw new CompanyException("Error: provided id is null. ");
        }
        Iterator<Employee> it = staff.iterator();
        while (it.hasNext()) {
            if (id.equals(it.next().getId())) {
                it.remove();
                return true;
            }
        }
        return false;
    }

    public int numberOfEmployees() {
        return staff.size();
    }

    public Employee getEmployee(int index) throws CompanyException {
        if (index < 0 || index >= staff.size()) {
            throw new CompanyException("Error: employee with index " + index
                                       + " does not exist. ");
        }
        return staff.get(index);
    }

    public Employee getEmployee(Long id) throws CompanyException {
        return staff.stream()
                    .filter(e -> e.getId().equals(id))
                    .findFirst()
                    .orElseThrow(() -> new CompanyException("Error: no employee with id "
                                                            + id + " exists. "));
    }

    // Kopie der Liste: von außen kann die interne Liste nicht verändert werden
    public List<Employee> getStaff() {
        return new ArrayList<>(staff);
    }

    // ---- Streams -------------------------------------------------------------

    public int numberOfManagers() {
        return (int) staff.stream()
                          .filter(e -> e.getRole().equals(Employee.Role.MANAGER))
                          .count();
    }

    public List<Employee> employeesSortedLastName() {
        ArrayList<Employee> sorted = new ArrayList<>(staff);
        sorted.sort(Comparator.comparing(Employee::getLastName));
        return sorted;
    }

    public List<Employee> employeesSortedSalaryDecreasing() {
        ArrayList<Employee> sorted = new ArrayList<>(staff);
        sorted.sort((Employee a, Employee b) -> (b.getSalary() - a.getSalary()));
        return sorted;
    }

    public List<Employee> employeesSortedSalaryDecreasing(int minSalary) {
        return staff.stream()
                    .filter(e -> (e.getSalary() > minSalary))
                    .sorted((Employee a, Employee b) -> (b.getSalary() - a.getSalary()))
                    .collect(Collectors.toList());
    }

    public void increaseSalaryByPercent(int percent) throws CompanyException {
        if (percent <= 0 || percent > 100) {
            throw new CompanyException("Error: invalid percentage provided. ");
        }
        // Im Lambda sind keine checked Exceptions erlaubt -> umverpacken
        staff.forEach(e -> {
            try {
                e.setSalary((int) (e.getSalary() * (100 + percent) / 100.0));
            } catch (CompanyException ex) {
                throw new RuntimeException(ex);
            }
        });
    }

    // ---- Dateien -------------------------------------------------------------

    public void serialize(String filename) throws CompanyException {
        if (filename == null) {
            throw new CompanyException("Error: filename is null. ");
        }
        try (ObjectOutputStream oos = new ObjectOutputStream(new FileOutputStream(filename))) {
            oos.writeObject(this);
        } catch (IOException e) {
            throw new CompanyException("Error: IO Exception. ", e);
        }
    }

    public static Company deserialize(String filename) throws CompanyException {
        if (filename == null) {
            throw new CompanyException("Error: filename is null. ");
        }
        try (ObjectInputStream ois = new ObjectInputStream(new FileInputStream(filename))) {
            return (Company) ois.readObject();
        } catch (FileNotFoundException e) {
            throw new CompanyException("Error: file not found: " + filename, e);
        } catch (IOException e) {
            throw new CompanyException("Error: IO Exception. ", e);
        } catch (ClassNotFoundException e) {
            throw new CompanyException("Error reading object from file. ", e);
        }
    }

    public void writeToFile(String filename) throws CompanyException {
        if (filename == null) {
            throw new CompanyException("Error: filename is null. ");
        }
        try (BufferedWriter bw = new BufferedWriter(new FileWriter(filename))) {
            bw.write(this.toCsvString());
        } catch (IOException e) {
            throw new CompanyException("Error: could not write " + filename, e);
        }
    }

    public static Company readFromFile(String filename) throws CompanyException {
        if (filename == null) {
            throw new CompanyException("Error: filename is null. ");
        }
        // Code-Wiederverwendung: Datei öffnen und an die InputStream-Variante übergeben
        try (InputStream is = new FileInputStream(filename)) {
            return readFromFile(is);
        } catch (FileNotFoundException e) {
            throw new CompanyException("Error: file not found: " + filename, e);
        } catch (IOException e) {
            throw new CompanyException("Error: could not read " + filename, e);
        }
    }

    // InputStream: funktioniert für Dateien UND für Uploads im Browser (Teil 4)
    public static Company readFromFile(InputStream is) throws CompanyException {
        if (is == null) {
            throw new CompanyException("Error: input stream is null. ");
        }
        Company company = new Company();
        try {
            BufferedReader br = new BufferedReader(new InputStreamReader(is));
            String line = br.readLine();
            if (line == null || line.contains(CSV_DELIMITER)) {
                throw new CompanyException("Invalid first line. "
                                           + "Single column with company name expected. ");
            }
            company.setCompanyName(line);
            line = br.readLine();
            if (line == null || line.contains(CSV_DELIMITER)) {
                throw new CompanyException("Invalid second line. "
                                           + "Single column with company address expected. ");
            }
            company.setCompanyAddress(line);
            line = br.readLine();
            while (line != null) {
                if (!line.isBlank()) {
                    company.hire(new Employee(line));
                }
                line = br.readLine();
            }
        } catch (IOException e) {
            throw new CompanyException("Error: could not read input. ", e);
        }
        return company;
    }

    public String toCsvString() {
        String csv = companyName + "\n" + companyAddress + "\n";
        for (Employee e : staff) {
            csv += e.toCsvString() + "\n";
        }
        return csv;
    }

    public String toString() {
        final String line = "------------------------------------------------";
        String str = "Company Name: " + companyName + "\n";
        str += "Address: " + companyAddress + "\n";
        str += line + "\n";
        str += "Staff: " + "\n";
        for (Employee emp : staff) {
            str += emp + "\n";
        }
        str += line + "\n";
        return str;
    }

Häufige Fehler

Fehler: new Company()

Company() has private access in Company.

Beim Singleton gibt es keinen öffentlichen Konstruktor – immer Company.getInstance() verwenden.

Fehler: Liste über getStaff() verändert

company.getStaff().add(e) hat keine Wirkung, der Mitarbeiter fehlt in der Firma.

getStaff() liefert absichtlich eine Kopie. Einstellen und Entlassen nur über hire und fire – dort finden die Prüfungen statt.

Fehler: Package passt nicht zum Ordner

IntelliJ meldet Package name 'at.spengergasse.company.model' does not correspond to the file path.

Die Datei muss in src/main/java/at/spengergasse/company/model/ liegen. Klassen am besten über New → Java Class im richtigen Package anlegen; beim Verschieben IntelliJs Refactoring (F6) verwenden.

Wissenskontrolle

Frage 1 Welche Aufgabe haben Model-Klassen in einer Anwendung mit Benutzeroberfläche?

Erklärung: Die Oberfläche zeigt Daten an und ruft Methoden des Models auf. Die Regeln selbst liegen im Model und funktionieren auch ohne Oberfläche, z. B. in JUnit-Tests.

Frage 2 Warum liefert ein Getter für eine interne Liste oft eine Kopie der Liste (defensive Kopie)?

Erklärung: Ohne Kopie gäbe der Getter nur die Referenz heraus. Wer der Kopie Elemente hinzufügt oder sie löscht, ändert das ursprüngliche Objekt nicht.

Frage 3 Welche Aufgabe erledigt ein DateTimeFormatter?

Erklärung: Mit einem Muster wie "dd.MM.yyyy" wird aus einem Datum der Text 24.11.2026 – und umgekehrt mit LocalDate.parse(text, formatter).

Frage 4 Mehrere Elemente sollen beim Durchlaufen aus einer Liste entfernt werden. Welcher Weg ist sicher?

Erklärung: Die for-each-Schleife bricht mit ConcurrentModificationException ab, und beim vorwärts laufenden Index wird nach jedem Entfernen ein Element übersprungen. Der Iterator ist dafür gemacht.
