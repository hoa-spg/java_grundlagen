1 — Statische Methoden

Die bisherigen Methoden werden auf Objekten aufgerufen: p1.setName("Max Maier"); oder p1.printPerson();. Sie ändern den Objektzustand, geben Informationen dazu zurück (p1.getName()) oder führen Berechnungen bzw. Aktionen aus (p1.bmiBerechnen()).

Manchmal will man eine Methode nicht einem Objekt zuordnen: wenn sie sinnvoll verwendet werden kann, ohne dass es überhaupt ein Objekt gibt, oder wenn sie keinerlei Objekteigenschaften verwendet. Dann gehört die Methode (nur) zur Klasse – man nennt sie statische Methode.

Beispiel: Ein Kurs nimmt bis zu drei Studenten auf (analog zum Auto). Die Methode aufnehmen(Student student) nimmt einen Studenten nur auf, wenn ein Platz frei ist und die Zulassungsvoraussetzungen erfüllt sind: Matura und Geburtsjahr vor 2003. Vielleicht will man das schon vor dem Aufnehmen prüfen:

Kurs.java (Ausschnitt) Java 
public class Kurs {

    ...

    public static boolean zulassungMoeglich(Student stud) {
        if (stud != null) {
            if (stud.hasMatura() && stud.getGeburtsjahr() < 2003) {
                return true;
            }
        } else {
            // TODO Fehlermeldung ausgeben
        }
        return false;
    }
}

Hier werden keine Objekteigenschaften von Kurs verwendet; die Methode funktioniert unabhängig von konkreten Objekten. Das Schlüsselwort static erlaubt den Aufruf ohne Objekt – statt einer Objektreferenz steht der Klassenname vor dem Punkt:

in der Testklasse oder sonstigen Klassen Java 
Student std = new Student("Max Maier", true, 2002);
boolean ok = Kurs.zulassungMoeglich(std);

Kurs ist hier die Klasse, keine Objektreferenz. Innerhalb der eigenen Klasse kann der Klassenname entfallen.

⚠
Die absolute Ausnahme

Statische Methoden sollen für dich zunächst die absolute Ausnahme sein. Viele Aufgaben ließen sich auch mit statischen Methoden lösen – das ist aber schlechtes (nicht objektorientiertes) Design. Und: Eine statische Methode kann nicht auf Objekteigenschaften (ohne this) zugreifen.

2 — Warum main statisch ist

Die main-Methode kennst du seit Lektion 1.5 als Einstiegspunkt eines Programms – in der kurzen Form void main() { … } in einer eigenen Datei. In den meisten Projekten und in älterem Code steht main dagegen in einer normalen Klasse und hat einen fest vorgegebenen Kopf. Nur wenn er genau so lautet, erkennt Java die Methode als Einstiegspunkt:

TeilBedeutung
publicvon überall sichtbar – auch für Java selbst, das die Methode beim Start aufruft (Lektion 1.5)
staticdie Methode gehört zur Klasse und kann aufgerufen werden, ohne dass vorher ein Objekt erzeugt wurde
voidkein Rückgabewert
mainder Name ist vorgeschrieben (klein geschrieben!)
String[] argsArgumente, die beim Start übergeben werden können (siehe unten)

Warum static? Beim Start eines Programms gibt es noch kein einziges Objekt. Java kann also keine Objektmethode aufrufen, sondern nur eine statische Methode der Klasse. Wenn auf einem Server ein Service gestartet wird oder auf deinem Rechner eine Desktop-Anwendung, geschieht das immer über eine solche Main-Methode. Da der Einstiegspunkt eindeutig sein muss, wird pro Programmstart genau eine davon ausgeführt. (Bei der kurzen Form erzeugt Java im Hintergrund selbst ein Objekt und ruft main() darauf auf.)

Programm.java Java 
public class Programm {

    public static void main(String[] args) {
        // erst hier entstehen die ersten Objekte, z. B.
        // Kursverwaltung kv = new Kursverwaltung();
        // kv.start();
    }
}

Typischerweise erzeugt main nur die ersten Objekte und übergibt dann an deren Objektmethoden – hier würde etwa die Benutzeroberfläche einer Kursverwaltung gestartet. Weil main statisch ist, kann sie nicht direkt auf Attribute oder Objektmethoden ihrer eigenen Klasse zugreifen (siehe „Häufige Fehler“). Der Parameter String[] args enthält Argumente, die vom Betriebssystem oder der Entwicklungsumgebung übergeben werden können – etwa eine zu öffnende Datei (was [] bedeutet, zeigt Lektion 2.2).

ℹ
Math und Random
Math ist eine Sammlung statischer Methoden – man ruft sie über den Klassennamen auf. Bei Random (Lektion 1.8) braucht man dagegen zuerst ein Objekt (new Random()), denn jeder Zufallszahlengenerator hat einen eigenen Zustand.

Häufige Fehler

Fehler: non-static from a static context

In main steht print(); oder name = "X"; → non-static method print() cannot be referenced from a static context.

Statische Methoden haben kein this. Zuerst ein Objekt erzeugen und die Methode darauf aufrufen: Mitarbeiter m = new Mitarbeiter(); m.print();.

Wissenskontrolle

Frage 1 Wie ruft man eine statische Methode quadrat(int x) der Klasse Rechner von einer anderen Klasse aus auf?

Erklärung: Statische Methoden gehören zur Klasse und werden über den Klassennamen aufgerufen. Es muss dafür kein Objekt existieren.

Frage 2 Warum ist die klassische main-Methode static?

Erklärung: Eine statische Methode kann ohne Objekt aufgerufen werden – genau das braucht der Einstiegspunkt eines Programms.

Frage 3 In public static void main(String[] args) steht die Anweisung print();, wobei print() eine normale Objektmethode derselben Klasse ist. Was passiert?

Erklärung: Eine statische Methode hat kein this. Zuerst muss ein Objekt erzeugt werden, auf dem man print() aufruft.

Frage 4 Welche Aussagen zur Klasse Math stimmen?

Mehrere Antworten sind richtig.

Erklärung: Alle Methoden von Math sind statisch und werden über den Klassennamen aufgerufen. Math.pow(2, 3) ist 2 hoch 3, also 8.0.
